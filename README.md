## 🚀 快速啟動說明

系統分為「後端伺服器 (backend)」與「前端介面 (frontend)」兩個部分。請依照下方步驟在您的電腦上啟動：

### 1. 啟動後端 API 伺服器
1. 開啟終端機（PowerShell / CMD）並進入 `backend` 目錄：
   ```bash
   cd backend
   ```
2. 啟動伺服器：
   ```bash
   node index.js
   ```
   *伺服器將在 `http://localhost:5000` 啟動，並自動在 `backend/data/` 底下建立 SQLite 資料庫與生成精美測試種子資料。*

### 2. 啟動前端開發伺服器 (支援 Android 手機連線)
1. 開啟另一個終端機，並進入 `frontend` 目錄：
   ```bash
   cd frontend
   ```
2. 啟動前端：
   ```bash
   npm run dev
   ```
3. 終端機會顯示類似以下資訊：
   ```text
   VITE v5.5.5  ready in 345 ms

   ➜  Local:   http://localhost:5173/
   ➜  Network: http://192.168.1.100:5173/  <-- 這就是您的區域網路連線 IP！
   ```

## 📱 安卓手機與平板同步操作教學

只要您的 Android 手機/平板與這台電腦連線到 **同一個 Wi-Fi 網路**，即可輕鬆開始同步使用：

1. 在您的 Android 手機或平板上，開啟 Chrome 或任意瀏覽器。
2. 在網址列輸入前端終端機顯示的 **Network 網址**（例如：`http://192.168.1.100:5173`）。
3. 即可直接在手機上操作、新增預約、查看報表！
4. **PWA 安裝**：在手機瀏覽器中點選「新增至主畫面」，即可像 App 一樣將系統直接釘在您的 Android 桌面，擁有更完美的沉浸式操作體驗。
